Summary cards can overlap: for example, a package without lyrics can also contain an error. FeedBack compatibility means valid package data that the current game may not display or play as intended. Authoring review highlights unusual but potentially intentional tab data. Lyrics and previews are optional; the Without previews view can still create a standard preview if you want one. Partial deep audio means one or more files use a format this validator cannot inspect deeply or exceeded its safety limit. Coverage does not make a package unhealthy. When a deterministic safe repair is available, Library Doctor shows a preview and requires confirmation before changing the package. If a Feedpak has multiple safe repair types, they can also be reviewed and applied together in one transaction. Recovery data is created first; the existing package is replaced only after a complete repaired candidate passes validation and archive integrity checks. No duplicate song is added to the library. Chart repairs retain an Undo copy. Preview repairs offer either listen-first review or confirmed automatic creation, then remove their temporary recovery data after success so the repair is fully finished. Song Tools can also replace an existing valid preview without requiring a scan finding. Findings that require musical judgment and have no guarded workflow remain report-only.
