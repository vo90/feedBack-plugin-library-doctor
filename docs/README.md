# Documentation status

Documents with dates or `phase-*` names record the implementation and review
state at the time they were written. They are historical engineering notes, not
current release policy. In particular, older references to required human
signoffs no longer block a Library Doctor release.

The current public-release plan is
`public-release-implementation-plan-2026-08-20.md`. Automated safety,
compatibility, packaging, and test checks remain part of the engineering
workflow; manual accessibility and volunteer usability checks are optional.
